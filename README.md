# Sudoku Solving Techniques

An interactive guide for learning and practising sudoku techniques, from naked singles to XY-chains.

The published page (`docs/index.html`) is encrypted and asks for a passcode. The readable source is
`src/index.html`. It is gitignored, so it exists only on the local machine.

Rebuild after editing the source:

    node build.mjs <passcode>
    git add docs && git commit -m "Update" && git push

Hosted with GitHub Pages from `main` / `docs`.
